# Logos Expand Grupo — coloque os arquivos aqui

Copie os arquivos PNG das logos com os nomes abaixo:

## Horizontal (ícone + texto "EXPAND | GRUPO")
- `expand-logo-horizontal-cream.png`  → versão creme/bege (fundo escuro)
- `expand-logo-horizontal-black.png`  → versão preta (fundo claro)
- `expand-logo-horizontal-gold.png`   → versão dourada (destaque)

## Vertical (ícone acima + texto abaixo)
- `expand-logo-vertical-cream.png`    → versão creme/bege
- `expand-logo-vertical-black.png`    → versão preta
- `expand-logo-vertical-gold.png`     → versão dourada

## Ícone isolado (símbolo apenas)
- `expand-icon-cream.png`             → ícone creme
- `expand-icon-black.png`             → ícone preto
- `expand-icon-gold.png`              → ícone dourado (gradiente)

## Brasão (crest completo)
- `expand-crest-cream.png`            → brasão creme
- `expand-crest-gold.png`             → brasão dourado
- `expand-crest-brown.png`            → brasão marrom/bronze

## Onde cada logo é usada no projeto
- Nav sidebar header: `expand-logo-horizontal-cream.png` (modo escuro)
- Nav sidebar header: `expand-logo-horizontal-black.png` (modo claro)
- Login / cover: `expand-crest-gold.png` ou `expand-logo-vertical-gold.png`
- Favicon (necessita conversão ICO): `expand-icon-gold.png`
